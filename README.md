# 📉 Customer Churn Prediction

Predicting which telecom customers are likely to leave using machine learning.

## Results
| Model | Accuracy |
|-------|----------|
| Logistic Regression | 78.75% |
| Random Forest | 78.54% |

## Dataset
IBM Telco Customer Churn — 7,043 customers, 20 features

## Tools
Python, Pandas, Scikit-learn, Matplotlib, Seaborn

## Key Findings
- Month-to-month customers churn 3x more than yearly contract customers
- High monthly charges (> $65) strongly predict churn
- New customers (tenure < 6 months) are highest risk

## How to Run
Open directly in Google Colab — no setup needed.
